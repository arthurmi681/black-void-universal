# Black Void Universal

**Qualquer pessoa pode aprender. Qualquer conteúdo. Qualquer perfil.**

Transforme qualquer conteúdo em materiais de estudo **extremamente acessíveis**, visuais e inclusivos — projetados para TDAH, TEA, Dislexia, Discalculia, Ansiedade, Baixa Visão e **todos os outros perfis de aprendizagem**.

Funciona com **qualquer IA** (Claude, ChatGPT, Gemini, Grok, etc.). Basta colar o prompt mestre + o link deste repositório. A IA pergunta suas necessidades e gera o material adaptado automaticamente.

---

## ✨ Por que isso é diferente

- **Ultra-inclusivo** — prompts específicos e detalhados para mais de 15 perfis de aprendizagem
- **Interativo** — a IA pergunta as variáveis uma por uma (não precisa preencher nada manualmente)
- **Adaptação real** — não é só trocar palavras. Muda estrutura, tom, tamanho dos blocos, exemplos e ritmo
- **Imagens que ensinam** — gera prompts prontos para imagens IA que realmente explicam o conceito
- **Múltiplos formatos** — PDF visual, Anki, roteiro para áudio, mapa mental, etc.
- **Pronto para imprimir** — alto contraste, fonte grande, espaçamento amplo, funciona bem em preto e branco
- **Zero conteúdo vazio** — só cria as seções que realmente fazem sentido para o assunto

---

## 🚀 Como usar (o jeito mais fácil)

### Passo a passo:

1. **Copie** todo o conteúdo do arquivo:
   ```
   prompts/master_prompt.txt
   ```

2. **Cole** na sua IA favorita (Claude, ChatGPT, Gemini, Grok, etc.).

3. **Cole logo em seguida** esta mensagem:
   > Use os prompts e regras do repositório: https://github.com/arthurmi681/black-void-universal

4. Responda as perguntas que a IA fizer sobre seu perfil, matéria, nível, etc.

Pronto. Ela vai criar o material completo adaptado para o seu jeito de aprender.

## 🧠 Perfis suportados

Cada perfil tem regras próprias de linguagem, estrutura, visual e tom:

| Perfil                    | Foco principal                              |
|---------------------------|---------------------------------------------|
| TDAH                      | Blocos curtos, atenção e dopamina           |
| TEA / Autismo             | Literalidade total e estrutura previsível   |
| Dislexia                  | Espaçamento grande, sílabas e leitura fácil |
| Discalculia               | Visualização extrema de matemática          |
| Ansiedade                 | Tom calmo, sem pressão, progresso claro     |
| Baixa Visão               | Alto contraste e texto grande               |
| Deficiência Auditiva      | 100% textual + diagramas visuais            |
| Disgrafia                 | Menos escrita, mais visual e digital        |
| Criança Pequena           | Linguagem lúdica e blocos divertidos        |
| Idoso / Memória           | Repetição, ritmo lento e associações        |
| Superdotação              | Versão compacta + aprofundamento            |
| Transtornos Sensoriais    | Visual minimalista e calmo                  |
| Baixa Motivação           | Passos minúsculos e recompensas rápidas     |
| **Combinado**             | Combina automaticamente 2 ou mais perfis    |
| **Geral**                 | Acessibilidade universal (bom para todos)   |

Você pode combinar perfis (ex: "TDAH + Dislexia" ou "TEA + Ansiedade").

## 📦 O que a IA entrega

- Texto estruturado com marcadores visuais (✅ ⚠️ 💡 🔑)
- Prompts prontos para gerar **todas as imagens** com IA
- Instruções exatas de formatação para PDF
- Versões alternativas (quando pedir): Anki, roteiro de áudio, mapa mental, etc.

---

## 📄 Como transformar em PDF

Depois que a IA entregar o conteúdo em Markdown:

- Cole no **Typora** → Exportar como PDF
- Use o site: https://md-to-pdf.fly.dev/
- VS Code + extensão "Markdown PDF"
- Ou peça para a própria IA te dar comandos para pandoc

---

## 💡 Dicas de uso

- Não tem texto para resumir? Descreva o tema normalmente (ex: "Faça um resumo sobre Leis de Newton para Ensino Médio").
- Quer versão para criança, vestibular, faculdade ou concurso? É só falar o nível.
- Pode pedir vários formatos na mesma conversa.
