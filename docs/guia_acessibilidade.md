# GUIA DE ACESSIBILIDADE — BLACK VOID UNIVERSAL

## Princípios Fundamentais
Todo material criado aqui deve seguir:

1. **Clareza acima de tudo**
2. **Respeito ao ritmo da pessoa**
3. **Zero julgamento**
4. **Visual que realmente ajuda a entender**

## Níveis de Adaptação

### Nível 1 - Universal (use sempre)
- Frases curtas
- Alto contraste
- Espaçamento amplo
- Sem ironia
- Imagens que explicam

### Nível 2 - Por Perfil
Veja os arquivos em `prompts/profiles/`

### Nível 3 - Por Combinação
Use `prompts/profiles/combinado.txt` + perfis individuais

## Dicas para quem for formatar o PDF

- Use fonte sans-serif (Arial, Verdana, Calibri, Open Sans)
- Tamanho mínimo 14pt no corpo (18pt é melhor para muitos perfis)
- Espaçamento entre linhas 1.5 ou 2.0
- Margens de pelo menos 2cm
- Evite texto justificado
- Use negrito para destaque, nunca sublinhado ou itálico sozinho
- Caixas com bordas coloridas funcionam bem
- Sempre teste o PDF em preto e branco

## Ferramentas recomendadas para criar o PDF

- Typora (fácil e bonito)
- VS Code + extensão Markdown PDF
- https://md-to-pdf.fly.dev/
- Pandoc (mais avançado)
- Canva (para quem quer mais controle visual)
- Google Docs (simples)

## Como testar a acessibilidade do material

Pergunte para si mesmo:
- Uma pessoa com TDAH consegue ler uma seção sem se perder?
- Uma pessoa com Dislexia consegue acompanhar o texto?
- Uma pessoa com TEA entende tudo de forma literal?
- Uma pessoa com ansiedade se sente segura lendo isso?
- Uma pessoa com baixa visão consegue ler sem esforço?

Se a resposta for "sim" para a maioria, o material está bom.
